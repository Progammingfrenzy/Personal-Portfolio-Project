I do plan to publish it to show it to jobs eventually and do more personal project to add to the project list.

## Tech Stack
- HTML
- CSS 
- JavaScript
- Devicons CDN
- Google Fonts (Orbitron + Rajdhani) 

## Features 
- Cyberpunk dark mode / pastel light mode toggle
- JS-driven skills grid with Devicon icons
- JS-driven project cards with expandable detail panels
- Project screenshots
- Blinking terminal cursor on name
- Responsive navbar with hover effects
- Animated View Details buttons

## Project Structure
index.html    → page structure
styles.css    → all styling + theme variables
App.js        → skills data, projects data, toggle logic
Project_Pictures/ → project screenshot images
